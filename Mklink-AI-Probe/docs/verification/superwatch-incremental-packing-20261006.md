# SuperWatch 增量组帧与批尾间隔优化（2026-10-06）

## 保留的实现

在原有 SWD/JTAG 读取循环中，每完成四组记录执行一次 CPU 打包和 CRC 更新。复用现有样本区与会话 TX 缓冲，不增加线程、DMA 通道、堆分配或第二份帧缓冲。单变量每块 32 B，四变量 80 B；最大 16 字配置每块 272 B。全速模式把 CPU 工作分散到读取之间，定周期模式可以利用剩余等待时间，不能宣称全速下有免费空隙。

帧构造分为 prepare / commit；prepare 不设置 pending、不递增发送序号，整批读取及末尾总线状态全部通过才 commit。CRC 延续同一个未取反状态，最后只取反一次，MLX1 / IEEE CRC32 线格式不变。因 SWD 时间预算提前结束的短批次，修正实际长度和组数并重新计算 CRC；不采用复杂的 CRC 合并状态。故障及 DAP 接管丢弃未发布数据。

打包缓存不可变参数、使用指针递增，避免 alias-safe 写入引发每个记录/字重复加载。对齐帧头直接四次 32 位写入。360 MHz 时间换算明确采用先除 8、再乘倒数的方法；实际 RV32 目标文件确认生成 shift / MULHU / shift，常用路径不再逐样本 DIVU。保留其他时钟和大跨度的精确除法路径。已验证所有 32 位范围内的 360 倍数两侧边界、50,000 组随机转换及 1–127 点分块/计数器回绕的完整打包结果，无精度换取速度。没有引入手写汇编：当前 C 已生成需要的乘法高位指令，未证实额外汇编有收益。

DAP 检查位置及排空/错误检查保留；分块 CPU 工作在采集锁内执行，增加的是一个有限块的处理时间，不能把“最高优先级”解释为零延迟。末尾补齐、短帧 CRC 修复、最终发布和 USB 发送仍在释放目标锁之后。RTT 的 1 ms 轮询、供电保护、显示最低优先级未改变。

STM32 单变量集中批尾明显缩短，但全速吞吐约下降 2.4%–4.1%，未稳定达到前期提出的“下降不超过 3%”建议线。按本次优先降低长空隙的目标保留，并明确记录这一代价。HPM 单变量和四变量的吞吐基本保持或小幅提升。STM32 四变量经常因 1 ms 预算形成短批次，需要末尾重新计算 CRC，所以改善有限。不能把单变量结论外推至所有布局。

原型 a5cb9367 在 STM32 单变量下降约 4.4%；上述热路径优化回收了一部分开销。随后尝试单变量专用循环（4892d729），未取得稳定附加收益，四变量回归更差，已撤回；最终不保留这条额外分支。

“额外批间时间占比”仍是时间指标：STM32 单变量从 17.33% 降至约 10.10%–10.99%，HPM 从 17.14% 降至约 11.59%–12.05%。不等于实际漏采率或误码率。全速批内中位仍为约 3 / 6 μs，但计算分散后批内 P99 可增大；必须联合观察批内、批间及总体速率。

新增实现没有消除孤立长间隔：保留版本一轮 HPM 四变量 100 μs 测试曾见批内 1879 μs，复测未再现，其归因未完成。典型批尾改善不能作为最大停顿上界，也不能证明微秒级短脉冲零漏采。USB 队列预留、CRC 合并及新增异步任务未引入；下个定位点应是孤立中断/调度尖峰及短批次重算成本。

## 正确性与边界

- 10 套原生固件测试通过：协议、SWD、SBA、运行时、目标仲裁、调度、帧格式、USB TX/DMA、供电换算。覆盖 CRC 任意分块位置；prepare 不发布、重复 commit/跨 epoch 拒绝；1–24 各种短批和执行增量工作后的故障丢弃。
- SWD 1–128 点带 CPU 回调及每笔访问故障；HPM 1–16 字、最终 sticky-status 故障及多个编译开关组合通过。总线访问次数、地址、最后排空与响应归属不变。
- SES 编译与 SWD 汇编布局门禁通过；关键 SWD 指令地址未移动。会话仍 1100 B，增量 builder 为栈上小状态，无新增静态采样缓存，堆和线程栈预留不变。最终真机检查：堆 total=12200 / used=10680 B；采集所在 Console 栈尚未触及空间 STM32 1656 B、HPM 1488 B。此为本轮路径高水位，不是所有功能的最坏栈上界。
- 两目标各 18 种真实变量布局逐字节通过，包含 1/2/4 字节、偏移 0–3、稀疏布局、块和边界；传输序号缺口和后端丢弃均为零。
- RTT 与四变量 Watch 同时运行时，OpenOCD 对两目标接管、halt/step、下载现有 ELF、校验、释放与显式重启采集通过；STM32 Bootloader 20 KiB 保持一致。全速测试进程启动至 halt 约 0.312 / 0.316 秒，这包括上位机启动时间，不是固件抢占延迟。
- 回退到保留固件后补验：两目标各 18 种布局共 34083 / 34456 个样本逐字节匹配；1 ms 设置下 OpenOCD 再次下载仿真及重启采集通过。已知 1 ms 计数器各约三秒，698373 / 381072 个样本、各 2999 次正常 +1，未见跳值，最大采样间隔 259 / 141 μs。重复值属于高采样率下正常重复观察；该证据不能证明微秒脉冲不漏采。
