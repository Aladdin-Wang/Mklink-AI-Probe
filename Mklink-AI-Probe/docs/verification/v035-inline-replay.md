# 0.3.5 原图日志回放

用户要求暂停后在原 SuperWatch 波形图回放，取消独立弹窗、取消旧缓冲区日志导出，并合并开始/停止记录按钮。

## 行为

- 加载日志后切换原画布的数据来源，保留原图的横纵轴、拖动、光标、阈值、通道布局和 PNG；原开始/暂停/停止按钮仅控制回放。
- 时间定位与视图调整暂停播放；暂停后可以查看完整历史，播放按日志时间推进，可选 0.25–16 倍速。
- 左侧显示日志通道与播放位置数值，勾选只影响显示；回放不写入目标或改变共享采集。返回实时恢复当前通道和采集状态。
- 解析仍在有界 Worker 中；过期定位结果、重新载入与组件卸载隔离。缩略图使用全日志的有界极值概览。
- 记录只在用户点击开始后创建，单个按钮切换停止；后台记录器及 GUI/CLI/MCP 协议保持一致。
- 独立 CLI 可视化页共用回放控制器，并使用其原有画布；不再打开独立回放图。
