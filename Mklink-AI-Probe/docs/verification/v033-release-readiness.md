# 0.3.3 候选回归与发布准备

2026-10-11，`0.3.3修复分支` / 草稿 PR38。仅准备本地未签名候选；没有合并、签名、修改更新渠道或发布。

## 本轮修正

### SuperWatch 分区高度与空状态布局

用户新截图暴露了此前布局验证的遗漏：没有可读符号时仍预留搜索区域，信号分组受到百分比高度限制；连接提示的 flex 收缩又会使其内容覆盖分组。

提示统一放在分组之前并保留自然高度。用户进一步指出固定高度仍会挤压，最终源码 `77f56f20` 改为可拖动的分区边界：信号分组、常用变量可上下调整，最后展开的区域使用剩余空间，各区域仍可独立折叠及滚动。高度保存于本地偏好，折叠、刷新后恢复；支持方向键、Home/End，双击恢复默认。窗口缩小时保留搜索区最低空间，空间极小时允许整列滚动。布局不写共享采样配置。

删除“隐藏配置”和“只看已选”两个顶栏按钮，并忽略旧版保存的隐藏标志，避免升级后目录或采样配置继续隐藏。保留“展开工作区”和搜索区自身的“仅已选”筛选。空组不再逐组重复占一行提示，说明放在组标题提示中。

实际 Chromium 使用生产 Vue 组件及应用样式、隔离模拟数据，检查断开设备、未选择符号、解析错误、空目录和 83 个变量 / 3 个分组 / 3 个常用变量。1200×720 下空分组三组完整显示，提示与区域不重叠；折叠前两区后搜索视口约 439px，刷新保留折叠状态。另检查 800×600 与 1600×900。截图留在本地构建目录；模拟数据不代替硬件验证。

最终可调高度版本在 1280×720 实际鼠标拖动分组 180→270px、键盘调整常用变量 150→130px，刷新与折叠后数值保持；双击恢复 180/150px。800×600 自动缩配并保持独立滚动。组件测试覆盖极端拖动边界、持久化、折叠，以及历史隐藏标志迁移；全量 GUI 89 文件 / 934 测试通过，生产 TypeScript/Vite 构建通过。

### 安装文件占用

安装器检查实际目标 GUI、sidecar、STCP 文件能否打开写句柄，使用 OPEN_EXISTING，不截断或修改文件。等待最多约 15 秒供正常客户端退出、共享后台空闲释放和冻结程序清理；仍占用时提供重试/取消，静默安装失败退出，不继续写入不完整的新负载。

检查放在交互安装维护页面之前，保护调用旧卸载器的升级路径；覆盖前再次检查最终目录，覆盖静默 /UPDATE；新卸载器也在删除前检查。没有按进程名强杀、删除共享锁文件、抢占其他客户端或重放硬件任务。检查不是跨整个安装过程的文件锁：检查后新启动应用仍可能产生竞争。

### 最新固件选择

每次升级重新查询既有 GitHub/Gitee 固件索引并要求缓存重新验证，比较对应 family/model 的版本，避免成功但滞后的主镜像固定旧版本。相同版本保留主渠道完整性元数据；一个渠道失败可使用另一渠道。继续校验长度、SHA-256、UF2 结构及型号，未改发布地址，未实际升级下载器固件。

### 在线烧录与 SVD 打包

源码 `8ea29231`、生产 Web `37a9328c`：校验进度以 HEX 有效数据量为分母；对齐块使用 pyOCD 的公开 32 位读取接口，非对齐段保持精确字节范围，保留完整逐字节比较。失败保留 USB 底层原因及阶段，不自动重试不确定的写入。

桌面及 Skill 强制包含经过摘要核验的 SVD Pack 包，收集 PDSC 引用的 SVD 并验证全部引用及 STM32F407VE 覆盖。使用现有白名单的 73 个 Pack，4800 个去重外设型号；FLM 仍为 7059 targets / 2224 blobs。缺少资源会使构建失败。

本机 V3 / STM32F103RC 用户工程源码全流程通过，10 MHz 与 30 MHz 均完成烧录校验；最终源码 10 MHz 校验约 0.299 秒，基线约 0.298 秒，**没有测得显著加速**。不能把本机结果当作客户 F405 的读线程异常已经修复。

第一候选 `8ea29231` 已实际覆盖安装并在 Windows-only PATH 下正常启动，安装文件与 NSIS 提取物一致；冻结 CLI、真实 stdio MCP、无外部 Pack 的 STM32F407VE 目录及 11601 个寄存器条目解析通过。安装态 F103RC 完整任务约 10.88 秒成功。它不包含后来追加的布局和安装器修复，不能作为最终候选证据。
