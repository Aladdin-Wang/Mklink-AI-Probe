# 0.3.3 SuperWatch 工具栏和配置记忆验证

日期：2026-10-10。分支：`0.3.3修复分支`，草稿 PR #38。
源码：`5444d3a5`；生产 Web：`32c69bb7`。

## 行为

- 右侧工具栏变为两行：工作区/目录/配置开关及调试速率一行；采集、缓冲区、间隔和显示工具一行。去掉重复标题和正常连接诊断信息，保留采样速率及异常提示。窄窗口横向滚动，不增加工具栏行数。
- 触发参数放入“触发设置”弹窗；不占常驻波形高度。
- SuperWatch 不创建原始日志面板，移除对应键盘入口及帮助；VOFA 原始日志不变。
- 移除手动项目保存/加载按钮。自动本地保存并恢复缓冲点数、采样间隔、触发参数、通道颜色/格式/阈值/纵轴及时间窗口，以及目录宽度、可见性与布局偏好。分组及已选项继续沿用既有共享工作区。不会从浏览器缓存恢复目标地址、类型、固件身份或覆盖共享工作区。
- “CSV”改为“导出采样日志”，与“日志回放”放在“日志”菜单。导出当前缓冲采样，不表示后台持续落盘录制；回放仍为本地离线模式。

## 共享架构

页面载入只读取后台状态；后台已经采集或暂停时，采用后台当前间隔，不自动设置硬件。后台停止时，本地间隔在用户点击开始后随单个 start 请求提交。

`/api/dash/superwatch/start` 向后兼容地接受可选 interval（1 µs 至 60 s）。参数在已有共享启动事务及资源准入中应用；已有采集不会被后到窗口重新配置。启动回调保留给独占操作恢复时，只首次消费该偏好，后续恢复不覆盖用户新设间隔。未增加锁，未修改原取消、租约和独占操作机制。
