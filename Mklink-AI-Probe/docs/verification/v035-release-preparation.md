## 有版本边界的既有实测

本轮较早的 b227f102 安装版已验证原生原图日志播放、暂停、滚轮缩放、拖动和
505168 字节 PNG 导出；未连接时在线/脱机入口、官方 Pack 导入、型号默认同步、
SVD/算法目录更新也通过。最新源码后续修正 Web 文件句柄的自动解析旁路，
上述结果不能替代新候选所有界面的再次验收。

之前 0.3.5 的换探针、RTT 双击自适应、串口无换行短数据与 49 字节导出、位域和
高频采集实测详见各专项报告。客户原始问题及高速并行限制继续保留，不因本轮
低负载通过而关闭。

## 发布前仍需处理

- UART 重配置首帧前额外字节来源；客户旧版 MSH 丢字及 status 6 的现场时序。
- 历史 MKLink HEX 下载在 2% 失败且 unknown；本轮 Keil 成功不代表该路径已修复。
- 浏览器文件句柄的真实选择/跟踪流程：自动化点击未弹出选择窗口，不能以模拟句柄测试替代。
- 真实 Modbus 从站、跨物理主机远程链路、其他 MCU、完整 RTOS Trace/YMODEM/保护/供电场景不具备完整本轮实测条件；没有执行破坏性覆盖测试。
- 历史 30 MHz 并行目标读错、各平台实体 USB/MSC 和正式更新验签仍按原限制处理。

验收发现的 Site Agent 版本、Skill 路由契约和 Web 自动解析旁路已修复，没有削弱测试。
