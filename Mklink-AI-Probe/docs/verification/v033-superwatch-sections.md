# 0.3.3 SuperWatch 可折叠分区

2026-10-10，分支 `0.3.3修复分支`，草稿 PR38。
源码 `0ed75a71`，生产 Web `b764ede3`。

## 行为

目录拆为“信号分组”“常用变量”“搜索变量”三个独立可折叠区域。
标题始终可点击，并支持原生按钮的键盘操作与 aria-expanded 状态。
折叠偏好存于客户端本地，沿用远程窗口隔离的设置键；损坏或不可写的
存储不会阻止使用。折叠不修改后端分组、已选变量或采样状态。

搜索展开时，信号分组和常用变量的高度受限，内容分别滚动；折叠后将空间
让给搜索列表。搜索收起时可扩大其他区域。“只看已选”模式适配新的外层区域。
440–720px 目录采用更紧凑的单行变量布局，更窄时保留名称与数值的两行布局。
搜索或“仅已选”过滤包含常用变量；常用区收起时，普通目录也不会排除这些变量。
搜索框与筛选栏不随结果列表滚动。
