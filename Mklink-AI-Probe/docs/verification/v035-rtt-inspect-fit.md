# RTT 搜索后通道预览与自适应布局

- 双击 RTT 容器、面板标题空白或下方空白，清除手动宽高并恢复按可用区域排列；控件、终端文本和曲线双击保留原操作。
- 自动搜索保留符号地址解析，然后在已连接且芯片 ID 非零时读取控制块。复用 Device 的 RAM 范围、签名、数量和描述符校验，只显示有效上行通道，查询不启动/停止或消费 RTT。
- 新共享能力 `rtt_inspect` 对应 `/api/device/rtt-control-block`，沿用身份、任务和调度准入；GUI/CLI/MCP 可访问同一结果。旧固件采集期间不绕过占用边界。
- 搜索预览与运行状态分离，空闲轮询不覆盖预览；地址/符号/连接变化使旧请求失效。
- 前端相关 56 项、后端初轮 292 项通过；两项新增 HTTP 测试因假设备缺少 port 失败，补全夹具后新增查询测试 6 项全部通过。TypeScript/生产构建通过。安装态和真实浏览器/硬件验证待完成，不用组件测试代替。
