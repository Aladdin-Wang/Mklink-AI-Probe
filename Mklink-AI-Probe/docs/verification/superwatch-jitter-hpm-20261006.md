# SuperWatch 间隔定位与 HPM 补验

本轮以原始 MUX 帧区分批次内、批次间时间差，采样率按完整变量组计算。基线与最终结果均为 30 MHz、无 RTT、每项三秒短测。STM32 基线为前轮固件，HPM 基线仍含旧看门狗主动休眠，因此 HPM 收益包含累计修复，不能全归因于本轮。

## 修改与原因

- HPM 每批首个样本重复等待一个完整周期。运行时已经等待该批次到期，底层仅对后续样本按周期等待。
- 电源任务固定换算采用软件双精度除法。临时板上计数测得平均约 49–55 μs，常量折叠及单精度换算后约 35–38 μs。保持任务优先级、10 ms 检查周期、电压控制和保护阈值。655,351 个十次 ADC 累加值与旧换算对比通过；三个只使用十项的百项数组缩小，节省 540 字节。
- CDC 每次发送清理完整 2 KiB DMA 缓冲的缓存，改为仅清理发送长度覆盖的完整缓存行。保持独立 DMA 缓冲、屏障、边界和 ZLP 行为。

临时诊断计数和命令分支已删除，没有新增循环打印；未修改 SDK、Arm2D 或 MicroBoot，未增加 WinUSB。

以上传输序号缺口、Watch 丢弃均为零。仍有真实采样间隔，不能等同于无漏采；短测最大值不能作为时延上界。STM32 单字全速批次内中位数 3 μs、批次间 175 μs，主要大间隔落在批次间，打包/发送与采样共用执行线程的开销仍存在。电源任务只解释部分抢占，尚未精确分离所有 USB 中断和调度耗时。

HPM 补测 19/20/21/1000 μs：19 μs 全速；单字 20/21 μs 中位间隔正确，平均约 43.7k/41.8k 组/秒；1000 μs 平均约 991 组/秒。四字读取中位耗时约 24 μs，20 μs 设置不能超越硬件读取时间。

## 正确性及 DAP

- HPM 18 种布局、33,271 个样本逐字节正确；确认已知非零测试模式，覆盖 1/2/4 字节偏移 0–3、分散区域及块边界。
- HPM RTT 单活动通道 + 四变量 Watch：OpenOCD 约 0.320 s 暂停，下载 41,564 字节、校验 38,508 字节、单步通过。恢复采样约 29.35k 组/秒，与抢占前相当，RTT 恢复。
- STM32 RTT 八通道 + 四变量 Watch：OpenOCD 约 0.321 s 暂停，APP 下载/校验通过，20 KiB Bootloader 不变；恢复约 16.84k 组/秒，八通道恢复。
- 固件编译、SWD 布局门禁通过；七组相关生产代码/调度回归通过，含 576 个 DMA、249,087 个 USB TX 边界场景。
