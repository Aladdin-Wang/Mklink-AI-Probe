# SuperWatch 分组与波形区统一验收

## 改动

- 一个分组对应一个波形区，统一新增、归属、名称、排序和删除。新增时可直接带入勾选信号，支持批量移动、单项选择及拖动手柄。
- 名称与折叠按钮分离，可选中复制；输入框不再置于可拖拽容器。折叠仅影响左侧列表。
- 每个信号可切换折线/采样点；采样点不连线，加粗增加点大小。主图和概览支持该样式，保留已有抽稀策略和原始采样时间。
- 工作区格式升级到 v2：兼容导入 v1，明确分组优先，旧波形区迁移为分组；保留中文别名、强调和配置。默认归属不随排序变化。
- 0.2.3 中英文更新说明压缩为四条，保留 nRF54L15 GUI 实机验收限制。
