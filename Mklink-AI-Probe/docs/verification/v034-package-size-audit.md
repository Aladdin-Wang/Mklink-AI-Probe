# 0.3.2 → 0.3.3 安装包体积核查

2026-10-11，作为 0.3.4 发布准备的一部分，检查本地归档的两版正式 Windows NSIS，解出实际 sidecar，并逐项读取其 PyInstaller CArchive 和内部 Pack ZIP。比较的是正式文件，不是开发目录占用。数字使用十进制 MB。

| 项目 | 0.3.2 字节 | 0.3.3 字节 | 增量字节 |
| --- | ---: | ---: | ---: |
| Windows NSIS | 96,829,674 | 176,557,369 | 79,727,695 |
| 内置 sidecar | 86,206,551 | 165,915,402 | 79,708,851 |
| sidecar 内 `builtin_packs` 压缩载荷 | 0 | 79,664,866 | 79,664,866 |
| sidecar 内 `builtin_flm` 压缩载荷 | 16,144,339 | 16,144,339 | 0 |
| sidecar 内 pyOCD 数据压缩载荷 | 14,704,157 | 14,704,157 | 0 |

新增 Pack 解释了安装包增长的约 99.9%。Python 依赖、既有算法库和 Web UI 没有出现同量级增长。0.3.3 的增长主要是补齐离线外设资源的实际成本，没有证据表明误装了完整 SDK、工程、开发依赖目录或多份应用。

## 新增资源组成

实际包内包含 73 个精简 CMSIS Pack，只保留 PDSC 引用的算法、SVD 和许可文件。以下压缩字节是 Pack 内 ZIP 成员的大小，不能直接与经过外层压缩的 NSIS 大小相加。

| 类型 | 文件数 | 原始字节 | Pack 内压缩字节 |
| --- | ---: | ---: | ---: |
| SVD | 624 | 1,453,958,173 | 70,313,520 |
| FLM | 596 | 52,034,680 | 13,165,469 |
| PDSC | 73 | 14,592,004 | 893,054 |
| 许可文本（含无扩展名） | 73 | 413,632 | 150,834 |

最大单项为 STM32H7 Pack（8,167,712 字节），其次 STM32H5（5,891,235）、STM32U5（4,217,881）、STM32L4（3,921,525）。没有单个异常巨大文件；体积主要来自多系列寄存器描述。

## 缺失和重复检查

- 73 个 Pack 的 SHA-256 与内置清单一致，许可证摘要一致。
- 逐项解析所有 PDSC 的 `algorithm`、`debug svd` 和许可引用：缺失引用 0，未引用文件 0，ZIP 同名成员 0。
- 624 个 SVD 按完整内容 SHA-256 比较，没有完全相同的重复文件。型号相近、内容相似不等于可直接互换。
- Pack 之间确有重复内容：FLM 重复副本的压缩合计 941,068 字节，许可文本重复副本 123,630 字节。许可随独立 Pack 保存，不直接删除。
- Pack 中 179 份 FLM、167 种唯一内容与 `builtin_flm` 算法库重叠，Pack 内压缩合计 1,431,979 字节。这与上一项重复量有交集，不能相加。当前 `algorithm_catalog` 和 pyOCD 按 PDSC 路径直接从 Pack 读取这些算法，删除会破坏算法来源或烧录。
- sidecar 顶层文件按内容比较的重复副本仅 7,084 压缩字节，两版相同；内部 Python 模块和 ZIP 内容需按层理解，不能把这一项当作所有语义重复的总量。

结论：增大约 82.3% 有明确资源来源，主要属于正常补齐。可进一步研究 SVD 跨文件压缩或统一算法存储，但那需要改变打包/读取方式及完整性校验，不能把现有引用文件当垃圾删除。本轮先保留资源覆盖面与兼容性，检查 0.3.4 候选是否有额外增长。

原始文件清单、逐项摘要、重复组及尺寸报告仅保存于本地构建证据目录，不把芯片资源或安装器提交到 Git。

## 0.3.4 本地候选复核

源提交 `63e167147656` 构建的未签名标准 NSIS 为 **176,582,099 字节**（176.58 MB），仅比 0.3.3 正式包增加 **24,730 字节**。SHA-256 为 `558315b0b9e6ab29783f0dde9df2259edfd543f62aacf94bb5671dc72022f1ea`。

解出实际候选 sidecar 后，2,299 项 FLM/Pack 资源与 0.3.3 逐项名称及内容完全一致，没有少装、重复追加或变更芯片资源。候选 sidecar 为 165,939,447 字节；冻结运行时、38 个生产 Web 文件及真实 stdio MCP 另行验证，见 [0.3.4 发布准备](v034-release-preparation.md)。这是本地候选核查，不是签名正式发布或实际安装验收。
