# 0.2.3 nRF54L15 在线安全操作阶段验证

日期：2026-09-24。分支：`codex/0.2.3-dev`。此记录只覆盖当前分支的源码和生产 Web 资源，不代表正式安装包或发布验收。

## 实现边界

- 在线安全能力仅对白名单别名 `nrf54l` / `nRF54L15` 开放。解锁采用 CTRL-AP 附加连接，先核对 TARGETID、CTRL-AP IDR、ERASEPROTECT、擦除状态及 AHB 可访问性；`ERASEALL` 只发一次。恢复后重新连接、核对 PARTID、全量检查主 Flash 和 UICR 空白。
- 加锁在固件校验之后核对 PARTID 和 UICR 空白，只向四个 APPROTECT/SECUREAPPROTECT 字写入 `0x50FA50FA`。随后由 CTRL-AP 复位，并核对保护状态为 3、ERASEPROTECT 未启用和 AHB 已关闭。
- nRF54L15 在线安全任务不切换 VCC。GUI、CLI、MCP 经同一任务后端；GUI 选择安全动作时自动设为附加连接或暂停连接、默认复位，并显示擦除程序与 UICR 的确认文案。脱机下载后加锁仍未实现。
