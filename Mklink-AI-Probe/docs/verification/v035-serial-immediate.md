# 0.3.5 串口收发视图即时显示

串口收发视图原先把 RX 数据当作换行分隔文本：只有收到 `0A` 或累计
4096 字节才提交一行。短二进制回复和没有换行的最后一段会一直留在 Worker
中，切换会话时还会被丢弃。后台字节计数增加而界面没有完整显示，不能据此
判定 UART 传输本身丢字节。

修复后每个后台原始字节批次立即提交显示，不根据 `0A/0D` 推断协议包。
后台保留原有最多 20 ms 的合批机制；界面保留有界历史和刷新调度。
原始字节、方向、批次时间戳保持不变，HEX 和导出不等待文本换行。
RX UTF-8 增量解码独立于 TX，避免多字节字符跨批次时乱码。
