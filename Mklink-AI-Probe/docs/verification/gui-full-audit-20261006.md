# GUI 功能审计与缩放修复（2026-10-06）

本轮实际操作 Windows 原生桌面与 Chrome Web GUI，并使用 STM32F103RET6 和两个 V4 下载器。安装态基线为 0.3.0 / `1acbf856`；以下新修复的最终安装态复验仍在进行。有限功能测试不等于长期稳定性认证，旧持续目标和长期验证保持暂停。

## 发现与修复

1. SuperWatch 在 50,000 点、约 200 kHz 下仅保留约 0.25 秒数据，图表却强制扩展为一秒，暂停缩放后开始会出现大片空白。时间范围改为真实保留范围，缩放到全部历史时不虚构额外历史。
2. 暂停消息到达 Worker 时，其环形缓冲可能已超前于界面最后一份摘要。冻结数据响应带上真实快照边界，界面据此重新请求范围，避免暂停后放大历史范围时左侧缺图。仅交互请求增加边界字段，不改变采集协议或逐点读取。
3. 图表所在 Grid 的隐式列宽受 Canvas 固有宽度影响，窄窗口右侧裁切；明确使用 `minmax(0, 1fr)`。
4. Memory 写入后的自动回读会把写入地址改为读取起始地址，导致下一次写入落错位置；只在写入地址为空时初始化，保留用户输入。
5. 新 GUI 窗口的 RTT 自动搜索未使用共享后台已经加载的符号；按显式路径、已连接设备的已加载符号、工程发现的顺序复用原解析流程。
