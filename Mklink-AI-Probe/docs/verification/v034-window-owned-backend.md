# 0.3.4 同一窗口原地切换下载器

后续更新：本文的“共享客户端/多个页面阻止切换”规则已被用户明确取消，现改为自动收尾并断开/切换，见 [明确连接控制](v034-explicit-connection-control.md)。下方验证保留为历史记录。

用户纠正了先前的“按探针跳转后台”方案：一个客户端持有一个后台，一次连接一只下载器；切换设备时后台进程、端口和认证保持不变。另开客户端才创建独立后台。此要求取代旧报告中的跨后台切换结论。

## 生命周期与互斥

- 后台具有独立 `runtime_id` 和固定工程上下文。物理探针只是一项可更换的连接，CDC/MSC 仍共享当前探针身份校验。
- Web、CLI GUI 和桌面代理启动独立窗口后台；SDK/AI 仍可按物理身份发现当前持有者并加入其会话，不自行打开第二条 CDC。
- 切换先取得目标探针的 OS 独占锁，再等待旧初始化结束、停止采集线程并关闭旧设备，之后更新发现别名和连接新设备。忙碌设备在拆旧连接前拒绝；新设备打开失败则保持新选择但未连接，不退回旧探针或重放操作。
- 同一窗口的后台 PID、监听端口、实例 ID、认证和页面地址保持不变，不导航、不重新启动页面。桌面代理保活和页面展示订阅计作同一个窗口。
- 其他 SDK/AI/UART 会话、另一个共享页面、活动远程连接、在途硬件操作、烧录任务会阻止改绑。用户应先结束这些共享使用；新客户端可独立连接未占用的探针。
- 主动断开释放探针所有权并保留窗口后台，其他独立窗口此时可以接手。关闭全部客户端仍沿用空闲退出策略。

## 设备数据与恢复

RTT、SystemView、SuperWatch、VOFA 的旧管理器、历史、符号订阅和二进制流被清理；独立串口/Modbus 保留。设备代次通知前端重建目标面板和烧录页面，清除全局符号缓存，拒绝旧符号请求的迟到响应。同一文件的符号 generation 即使相同，也不会保留旧设备数据。新设备采集由用户重新开始。

探针的任务日志在切换前读入并合并已有记录，保留原探针标识及 `unknown` 状态；同一 request ID 不会因切换变成新操作。过期客户端再次连接时校验当前物理身份，不能因为后台实例仍相同而访问另一个探针。

稳定外设 ID 和可选外设恢复失败不阻断设备连接的修复继续保留。固定工程中的符号文件和显示偏好可继续使用，不跨设备继承旧 MCU 推断。

## 验证记录

初轮实际生产 Web 和桌面代理验证：V3/STM32F103 使用原工程原位置 ELF，RTT 与 SuperWatch 运行中切至第二只实体下载器，后台 PID、端口、实例 ID 不变，旧数据归零；切回成功。SystemView 运行中的同样切换成功。第二只下载器未连接目标板，目标采集不在其验证范围内。

最终生产 Web/代理与两只实物下载器复核：

- 同窗口 A→B→A、SystemView 运行中 A→B、再次切回 A，全程后台 PID、端口、实例 ID 不变，代理页面不重载；RTT 行数和 Trace 事件历史在 B 上归零。
- A 上 RTT 和 SuperWatch 并行，3 秒收到 30 行、Watch 283 周期，读错误为 0；独立 Trace 验证 3 秒收到 14093 事件。
- 窗口二独立连接 B，窗口一尝试切入 B 返回占用错误，A 上 RTT/Watch 继续运行。窗口二主动断开后窗口一可接手 B，再释放给窗口二；双方后台身份保持不变。最后恢复窗口一连接 A。
- 原位置 ELF 正确加载，5365 个变量；未复制工程或改写下载器固件。B 无目标板，只验证连接、占用与切换，不声称 B 的目标采集通过。
- 最后补充保护：同一桌面代理若打开两份页面，仍计为两个共享页面并阻止切换；只去重代理保活记录，不合并真实页面。此边界 29 项回归通过，并重新启动最终代码执行 A→B→A 真机复核。

软件验证：Python 全量初跑 4771 通过、2 跳过，1 项旧入口参数断言失败、4 项独立打包夹具缺少本地 FLM 资源。更新协议断言后最终相关回归 1177 项通过；页面保活边界补充回归 29 项通过。指定已有本地资源目录后，干净环境实包、审计与进程生命周期测试 5 项通过；冻结后台测试改用明确的窗口 runtime_id 发现端点后，使用同一份新构建实包重跑 1 项通过。该测试同时覆盖 Windows-only PATH 下启动、双 UART 客户端分离与后台退出。全量前端初跑 938 通过、2 项旧导航夹具失败；补充设备状态及换设备清空烧录表单断言后，两项重跑通过，最终 940 项通过覆盖。TypeScript 与生产构建、diff 检查通过。

测试日志、硬件标识、原始路径和截图仅存于忽略的本地构建产物目录。保留一个最终 WebGUI 供用户继续测试，第二个测试窗口及后台已退出。未重建安装器、变更供电、合并 PR 或正式发布。
