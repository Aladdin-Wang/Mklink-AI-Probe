# 文件来源路径历史

2026-10-10，源码 `132cb364`，继续使用 `0.3.3修复分支` / 草稿 PR38。

配置页 AXF/ELF 输入框新增最近使用路径下拉列表，最多保存 10 条，重复路径移到
最前。点击或聚焦显示全部历史，编辑时按路径文字筛选；支持鼠标选择、上下键、
回车和 Escape。每条可单独移除，移除不删除文件、不改变当前路径。

手动输入完成、浏览选择原文件、点击解析以及选择历史项时记录路径；沿用现有
路径保存和 RTT 地址失效流程。仅选择历史不会自动解析、连接设备或更改共享后台。
首次使用从原有单条设置迁入历史，删除后不因重新挂载组件而恢复。浏览器上传的
快照路径不进入原文件历史，避免将临时上传缓存当成可持续跟踪的文件。

历史保存于当前客户端的本地存储，与桌面设置使用相同的远程窗口隔离边界。
桌面使用固定应用来源；普通浏览器按站点来源保存，不跨浏览器、主机或端口同步。
清理站点数据会清除历史；文件已移动/删除时，解析仍按既有流程报告文件错误。
