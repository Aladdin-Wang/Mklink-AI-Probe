# 0.3.5 Pack 外设同步与手动 SVD

源代码和生产 Web：`d5a65482`，分支 `codex/0.3.5-fixes`，PR43 草稿。

## 原因与修改

在线烧录和 SuperWatch 本来读取同一份已安装 Pack 状态，但外设 API 首次生成非空索引后不再刷新。后续导入的型号能被在线烧录识别，却不会进入已有后台的外设搜索结果。

外设索引现在根据 Pack 状态、索引和工程配置文件的修改信息失效；输入型号及重新聚焦搜索框会查询最新索引。另外增加“刷新芯片包”，用于强制重新发现外部安装的 Pack。型号和 SVD 仍依据 PDSC 的明确对应关系，不猜测文件。只有 FLM、没有 SVD 或未在 PDSC 声明 SVD 的 Pack 不会产生外设目录。

“加载 SVD 文件”复用现有外设选择、只读过滤和工程恢复流程。浏览器上传文件先校验，再保存到工程持久目录；桌面选择本地路径。上传限制 32 MiB，拒绝错误扩展名、空文件、无效 XML、非 device 根和没有支持寄存器的 SVD。采集中切换被拒绝，当前配置保持。

## 验证

- Python：`test_peripheral_import.py`、`test_peripheral_watch.py`、`test_peripheral_unified.py`、`test_remote_api.py`，最终 **138 passed**。包括真实 PackManager 导入/移除后非空缓存更新、显式刷新、重复上传、重建 manager 后恢复、错误文件清理及采集中配置保护。初跑两项旧 mock 不接收新关键字参数；更新 mock 签名后完整重跑通过。
- GUI：外设面板、文件选择器、API composable，**33 passed**。覆盖浏览器上传、桌面路径、取消、失败保留、设备变化后忽略迟到选择和原查询刷新。
- TypeScript 与生产构建通过，已更新跟踪的 `gui/dist`。Vite 大块提示仍存在。
- 真实 Edge + 生产 Web + 实际 HTTP：预热非空目录并确认新型号缺失，通过在线烧录 Pack 导入接口成功导入，重新聚焦原查询即可选择并加载外设。浏览器文件选择器上传独立 SVD，显示 12 个支持项；错误 XML 保留原选择；页面重载恢复成功。最终页面按钮及长路径换行目视检查通过。

浏览器使用离线 Device 夹具，禁止目标内存读写；本轮验证目录、导入和界面，不宣称新增芯片真机采样通过。桌面路径经过组件验证，本次未重新构建安装包或覆盖安装，全局 Skill 未替换。之前位域/时钟的硬件与安装结论仍分别以对应报告为准。

本地证据位于构建根 `reports/peripheral-import`，包含浏览器脚本、JSON 和截图；不提交 Pack、SVD 夹具或截图。测试入口保留了含链接的临时运行目录，没有强制清理。
