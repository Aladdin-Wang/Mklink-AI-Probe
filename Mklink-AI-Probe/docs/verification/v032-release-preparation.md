# 0.3.2 发布准备与回归核对

本报告区分旧候选已通过、新改动测试以及最终候选待验收项目。准备发布不等于已发布，
PR35 保持修复分支；不修改 0.3.1 标签、正式包和更新渠道。

## 本轮补充修复

- SWD 时钟界面使用 MHz，配置和 API 仍存整数 Hz，兼容旧配置及小数 MHz。
- 高速档位未确认但固件明确确认回退 1 MHz 时，保留连接并显示提示；回退本身未确认时
  不声称连接成功。V3/V4 延后时钟设置漏回 profile 的修复由固件会话完成。
- RTT 与串口显示模式统一称为“收发”，默认显示 `HH:mm:ss.SSS` 与 RX/TX。
  RTT 发送显示仅记入后台确认接受的字节，发送失败不伪造成功记录。
- 多 RTT 面板支持独立拖动尺寸，折叠时释放空间。
- 原生 Mac 生成 `.app.tar.gz` 更新载荷；Linux 为 AppImage、DEB 分别生成平台条目。
  发布准备核对三平台同版本、同源提交、文件哈希和相邻签名，发布器将这些条目写入两个
  更新源。候选构建不读取正式私钥，不代表已完成签名更新实装。
