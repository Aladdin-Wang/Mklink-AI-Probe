# 0.3.5 短暂掉线恢复与重载提示

2026-10-17：用户已升级下载器至 V3.6.5，要求将此前持续采集的 CDC 995 故障保留为
待排查，并改善短暂断链恢复。后续明确：**仅有 5 秒自动恢复窗口**，超过后视为用户
可能主动拔走，保持断开。旧故障根因没有因此关闭，见 `v035-cdc-995-disconnect.md`。

## 行为

- 共享后台检测已连接设备的 CDC 传输故障后，等待原 USB 身份，支持该身份的 COM 变化。
  在 5 秒内重连成功才恢复原 RTT/SuperWatch；超时进入 `expired`，之后插回不会自动连接。
  迟到的连接完成会关闭，不自动恢复采集。窗口内失败尝试有退避与上限。
- GUI、CLI、MCP 共享此机制。窗口内保留原 AI 心跳、订阅、符号版本和采集所有权。
  超时不自动新建会话；用户明确要求重连后才使用正常连接入口。
- 主动停止、断开、切换、关闭、租约过期及已接纳任务均保留优先权。不重放写入、RTT 发送、
  复位、烧录或未知结果的任务，不打开另一只下载器。
- 固件文件变化时不解析新符号、不恢复旧地址采集；继续要求手动重载。暂停状态保留。
  新采集使用新时间段，断线期间数据无法补回。已有日志保留；记录因故障停止后需重新开始。
- 顶栏显示等待、恢复和超时状态。重载提示改为与下方分组相同的背景、底边框和紧凑次级按钮，
  去掉橙色整框和大号实心按钮，原来的手动确认流程保留。

## 已完成验证

- 恢复、重连、任务排空、共享会话、关闭、CLI/MCP 与无目标连接的针对性 Python 测试通过。
  其中最终 5 秒边界与重连组 49 项通过；共享运行时相关组 133 项通过。
- GUI 状态、变量面板和 API 组 54 项通过；生产 Web 编译通过（最终包另行记录）。
- 初版恢复逻辑实机验证：V3.6.5、F103，直接拔 USB 后插回，首次重连恢复 RTT 和 SuperWatch，
  原 AI 会话读取 CPUID 成功。该次测试发生在新增 5 秒限制之前，不能替代最终超时验收。
- Chrome 已检查紧凑重载框。使用复制的 AXF 改变尾部非装载内容触发提示，未修改原工程固件；
  已恢复原 AXF，停止测试采集并通过正常 API 断开、关闭测试代理。

证据位于构建根 `artifacts/v035-auto-recovery`，包括恢复前后状态、时间线、AI 读取和 UI 截图。
最终安装包及 5 秒窗口的实机结果待补；尚未合并、签名或正式发布。
