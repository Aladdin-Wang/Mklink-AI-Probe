# SuperWatch 工作区与嵌套成员搜索验收

日期：2026-10-02。基于 main `0cee0fae294a`，分支 `codex/superwatch-workspace`。

## 功能与用法

- 已选信号点击“整理”可新建、命名、排序和删除分组。折叠分组只隐藏列表行，采样和曲线保持；圆点按钮单独控制波形可见性。
- B 按钮加粗名称及曲线。名称输入支持中文，原始变量路径保留在提示中，采样身份仍使用原始路径。
- “新增波形区”可创建多个区域，每区可以分配多个信号，具有独立纵轴、共享时间轴。支持批量分配、区域排序、高度滑块和分隔条拖动；删除区域将其信号移回首区。配置上限为 64 个区域，超过可见高度时滚动查看。
- “展开工作区”占满应用内容窗口；“只看已选”“隐藏配置”减少辅助面板，Esc 退出专注。切换布局不重建采集会话。
- 分组、中文名称、强调和波形区保存在项目目录的 `.mklink/superwatch_workspace.json`。Web/桌面读取相同项目配置；保存项目 JSON 可携带这些设置，加载时校验版本和结构。并发修改通过 revision 检测，冲突显示错误并保留原配置，刷新后重试。
- CSV 导出列名为 `中文名称 [原始路径]`，无别名时保留原列名。离线回放保留该名称。
- 搜索空格表示同时匹配，逗号表示任一匹配，例如 `CCU ABC, PWM`。支持路径、类型和已配置别名；仅输入 `bat_num` 也可检索结构体深层成员。

## 搜索原因及修复

目录为控制初始解析成本，对每个根变量的预展开叶节点数量设有限制。此前搜索只扫描这份列表，排在大数组之后的结构体成员即使 DWARF 中存在，也可能搜索不到。搜索现在补充遍历 DWARF 类型树，依据成员名称剪枝数组，不依赖用户先展开目录；不解引用指针，保持可采样 RAM 范围检查。

增加 `HouTai_data.Prama_Set.bat_num` 用例：在前置大数组和每根仅 2 个预展开叶节点的条件下，单成员名及多词搜索均返回正确完整路径和地址。客户原始 ELF 未提供，此为确定性回归用例，未宣称原工程实测。
