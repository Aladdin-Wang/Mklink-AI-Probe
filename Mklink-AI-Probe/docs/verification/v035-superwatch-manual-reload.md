# 0.3.5 SuperWatch 手动重载与界面精简

编译结束不代表目标板已下载新固件。文件监控现在只在文件稳定后发布待重载事件，
不再预解析、比较布局或静默应用符号，即使只有时间戳变化或地址完全相同也需用户确认。
当前采集和变量目录保持不变；显式重新加载仍使用共享后台的排他事务、变量迁移与
采集恢复机制，用户主动停止的采集不自动恢复。

SuperWatch 每个新的文件变更事件弹窗一次，可选择“稍后”；重复轮询不会反复弹窗。
待重载时，变量面板顶部保留醒目的“重新加载变量”按钮，不依赖搜索区域是否展开。
移除搜索旁的手动添加和粘贴 C 结构定义入口；已有变量的结构定义修复能力保留。
曲线名称列表默认收起，点击展开、再次点击收起，移开鼠标或更新通道不自动开关。
0.3.5 中英文更新说明合并为六条用户可感知变化。

发布验收补查发现 Web 文件句柄仍有独立的自动上传/解析路径。e577efc7 将其改为
稳定检测后只提示；显式确认时才上传快照，沿用共享后台的重载事务。后端校验原符号
身份，防止旧页面覆盖另一客户端选定的来源；失败后保留待处理状态，允许显式重试。
加载中发生的新编译继续待确认。仅修改时间变化也会提醒，不修改 RTT 地址或清空目录。
文件跟踪与共享后台参考文档同步更新，避免继续引导用户等待自动重载。
