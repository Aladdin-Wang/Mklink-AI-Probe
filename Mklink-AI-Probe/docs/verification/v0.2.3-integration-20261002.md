## Integration fix

The live-write PR adds JSON write events to raw TXT logs. The replay PR initially
treated these as samples and rejected the exported file. The shared parser now
recognizes validated write metadata before format detection, counts it separately
and leaves the sample clock unchanged. The replay dialog shows the event count;
it does not draw replay write markers. Tests cover mixed TXT/JSONL, metadata before
the first sample, malformed metadata and event-only files.
