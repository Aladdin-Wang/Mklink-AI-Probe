# CDC 多路复用：GUI / AI / CLI / MCP 接入验收

2026-10-05。主机分支 `codex/v0.3.0-shared-runtime`、后台协议 47，配套 V4
固件分支 `codex/v4-multiplex-runtime` 的 `58c47a9`。本轮为短时开发验收，未发布、
未合并，也未生成新安装包或覆盖本机旧 Skill。生产 Web 前端已构建并纳入源码提交。

## 实现

- 保留现有每探针共享后台、单串口句柄、单读取线程。新增 `MuxTransport` 只做帧
  解析、一个在途请求及事件分发；不另建串口连接/读取线程，不给各客户端复制设备层。
- 根据 `MUX_TARGET=1` 协商。旧固件仍使用旧单通道 RTT；新固件使用 epoch、随机
  nonce、递增请求编号和 CRC 帧。读写分片最大 128 字节，心跳每秒发送一次。
- RTT 和 SuperWatch 分别占用采集租约，复用原有采集管理器、数据解码和绘图。
  允许内存/变量/外设寄存器及批量内存读取与采集共存。烧录、复位、时钟、调试控制、
  独立 SystemView/VOFA 继续要求显式停流。在线/脱机任务也纳入采集资源互斥。
- RTT 可订阅目标实际存在且活动的 0–7 通道。原日志/终端/曲线显示主通道，新增
  独立通道查看和下行通道选择；不把各通道的二进制数据拼进同一个文本解析器。
- 原始数据缓存每通道 64 KiB，单次读取最多 16 KiB；每个客户端独立持有
  session/cursor。缓存覆盖、协议事件序列缺口和接收队列丢弃分别记录。
- CLI 增加 `rtt --channels ... --addr ...`，MCP 增加 `rtt_read_channel`、
  `rtt_write_hex`，`rtt_start`/`rtt_write` 增加通道参数；共享 SDK 复用相同能力。
  MCP 输入限制仍为每次 256 字节。旧映射模式的保留停止串由旧 Device 路径保护。
- SuperWatch 将较大逻辑区域拆成最多 15 个、各不超过 128 字节的物理区域；按完整
  有序轮次还原现有帧。最短固件周期 2 ms，多区域不保证原子快照。
- 超时/CRC/会话失效不重放、不自动回退 Pika。现有端口锁旁的模式标记仅记录是否
  曾进入帧模式，供显式重连执行 HELLO/EXIT；它不承担锁、租约或命令恢复功能。

## 验证结果

| 验证 | 结果 |
|---|---|
| 相关 Python 回归 | 1362 passed / 2 skipped；最终读取线程局部状态修正后再跑相关 69 项全部通过 |
| GUI 回归 | 整套 84 文件、851 项通过；最终通道参数/游标修改后相关 52 项通过（含新增 2 项） |
| Skill/反馈契约 | 66 项通过；修正仍写死旧 V4 0–2 通道上限的文档断言，分别检查旧/新固件边界 |
| 生产构建 | TypeScript 检查与 Vite 构建通过；保留现有大 chunk 提示 |
| 底层 STM32 3 秒短测 | RTT 0 接收 9030 B、RTT 1 接收 121733 B，同时收到 273 个采样帧和完成 406 次读取；平均 2.10 ms、最大 3.03 ms |
| 显式重连 | 成功模拟丢失主机会话并重新连接；没有重放原请求 |
| 共享 API + MCP + CLI | 两路 RTT、SuperWatch 同时运行；不同客户端读缓存互不消耗；MCP 读通道 1 二进制、CLI 读通道 0；CLI 独立创建有限多通道采集通过 |
| 写入 | 采集期间对测试工程预留变量单元写入、读回、恢复原值并校验；RTT 下行发送及 MCP 二进制发送入口通过 |
| 最终共享短测完整性 | 协议事件缺口、RTT/Watch 接收队列丢弃均为 0；不等于目标 RTT 环形缓冲永不溢出 |
| 真实网页 | Edge 加载生产构建，GUI 启动 0/1 通道并显示通道 1 HEX；再启动 SuperWatch，独立 stdio MCP 同时读 RTT/内存；GUI 停止成功，无页面异常 |

物理测试使用已连接的 STM32F103 板；未烧录目标 MCU、改变供电或主动复位。
写入仅涉及测试工程预留 RAM 单元且已恢复。测试窗口和后台结束，未留下持续采集。
设备身份、具体地址、屏幕截图和原始日志仅保存在本地忽略的构建目录。

## 验收边界

- 全仓测试曾尝试，离线安全算法用例报告“内置选项字节算法不匹配安全白名单”；
  本轮未修改该实现。随后全仓运行又进入需联网构建的 wheel 环境，已结束该运行，
  改为覆盖本次通信/资源/远程/共享调用链的上述回归集。不能声称全仓测试通过。
- 物理多通道验证为两个 Up、一个 Down；8 通道上限不是 8 个实体通道的验收记录。
- 未验证 HPM/JTAG、跨主机远程多通道、长时间采集、系统休眠、真实中途拔线和掉电。
  HPM 未接；长期验证继续按用户要求暂停。
- 外部串口助手的旧 RTT 映射保留，但助手与共享后台仍不能同时打开同一个 CDC 口。
- 本轮交付为源代码及构建好的 Web 前端。已安装的桌面程序/本地 Skill 仍是之前
  的安装版本，需后续配套打包更新。开发 PR 保持草稿，不自动合并或发布。

用户操作及限制见 [共享后台使用说明](../../references/shared-runtime.md)。
