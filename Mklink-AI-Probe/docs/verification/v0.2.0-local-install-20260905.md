# 0.2.0 本地覆盖安装验收（2026-09-05）

## 范围

用户要求重建安装包、覆盖本机安装并整理交接。本轮收口现有在线/脱机安全操作、
全片擦除、型号联想、本地/U 盘 FLM 路径以及短步骤引导；保留既有能力限制。
版本信息仅作概括，长期芯片安全任务移到 [维护路线图](../ai/security-roadmap.md)。

仅构建标准 NSIS 本地候选，不发布、不改版本标签或更新索引。使用维护 builder
新增的 `--local-bundle`，不读取签名密钥，不生成 updater `.sig`；已有正式签名
流程保持不变。包仍无 Authenticode 签名，Windows 可能显示未知发布者。

## 验收结果

构建、安装及进程检查完成后在此补齐最终结果；未完成前不视为已安装。

- 打包、内置算法与在线/脱机定向测试：363 项通过。
- Python 全量：1845 项通过，12 项因 Windows 符号链接权限 `WinError 1314`
  无法建立测试前提而失败；未改变 ACL、权限或删改测试以掩盖限制。
- GUI 首轮版本文案断言过时，同步后全量 654 项通过（60 个文件）。
- 原始固件备份和唯一硬件证据保留，未因精简交接而删除。
- 本轮全量测试产生的带链接临时目录按规则保留；具体位置见本地测试日志，
  不强制删除。交接精简不等于清空 `.build`。

确切源提交、候选包大小、SHA-256 和安装证据保留在本地 `.build`，正式发布需要
单独验收。此次安装验证不操作目标保护、擦写或 VCC，不替代此前真机报告。
