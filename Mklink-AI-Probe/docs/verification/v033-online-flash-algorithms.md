# 0.3.3 在线烧录布局与算法映射验证

- 源码：`92e33221`；生产 Web：`ee0c2024`。
- 左栏连接参数折叠为带摘要的设置区，展开后双列；器件资源按钮统一图标与尺寸，“联网更新”改为“联网下载”。
- 算法候选显示来源、地址范围与“镜像使用”标记；映射详情可折叠。允许选择内置、Pack、自定义 FLM；同地址替换，不相交地址可组合。
- 新增 `algorithm_ids`，旧 `algorithm_id` 兼容。预览与任务核对选择集合、算法身份及资产摘要，所选 Pack FLM 传入执行后端，禁止无覆盖时静默回退。多算法使用镜像覆盖/所选扇区擦除，不支持无边界全片擦除。
- 共用算法解析器支持连续镜像跨相邻算法边界，同时保留已有完整覆盖算法的选择优先级。沿用现有资源所有权与配置事务；算法发现由工作线程执行。

## 验证

- GUI 在线烧录相关测试 120 项通过；TypeScript 与生产构建通过。
- Python 在线 API、算法目录、自定义 FLM、后端、HEX、共享选项、作业、安全与离线下载/部署/身份共 530 项通过。
- 初次未指定本地 FLM 资产目录，21 项离线安全白名单检查失败；加载改动前 HEAD 模块后同样失败。指定主工作区现有 `MKLINK_BUILTIN_FLM_ROOT` 后 530 项全通过，未改白名单。
- 生产服务只读/文件检查：真实内置 STM32F103RE FLM 选择、32 字节 BIN 地址映射及 2 KiB 扇区解析通过。无 USB 枚举或任务执行。
- 真实浏览器运行生产组件、模拟 API：1600×900 与 1200×720，双分区 HEX、同地址替换、外置算法保留、未覆盖时阻止开始、映射展开及窄屏滚动操作通过；控制台无错误。
