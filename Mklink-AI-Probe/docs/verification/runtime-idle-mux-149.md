# 149：固件帧协议与后台空闲退出

2026-10-05，有限验证；长期运行测试仍暂停。

## 固件

V4 独立分支 codex/v4-multiplex-runtime，草稿 PR1。4ab77c2 已编译并通过 UF2 升级。
只实现 MUX_FRAME=1，MUX_TARGET=0；多通道 RTT 和目标调度尚未交付。
小分片实测发现 USB IRQ 入队与任务出队竞争；应用层单字节出队短暂关中断修复，未改 MicroBoot。
分片、CRC 恢复、旧 epoch 拒绝、二进制透明及退出旧命令模式通过。
STM32 ID/RTT 控制块读取和原 RTT 1.5 秒日志回归通过。未改目标固件或电压，HPM 未连接。
ILM 不变，DLM +15 B、AHB +300 B、Flash +852 B；DLM 仅余 476 B，后续缓冲需使用预算化 AHB 池。

## 后台

旧 python -m mklink serve 来自历史 SuperWatch 测试，不属于当前后台注册目录；
检查无 TCP 客户端、设备未连接、资源为空后结束对应进程，8770 已释放。
当前代码已删除旧 serve 入口，本次修复针对共享后台生命周期。
协议45：60秒无客户端宽限期、5秒检查，复用既有正常关闭流程释放采集/设备/端口。
GUI登记、AI/CLI会话、在途请求、硬件锁、UART操作、烧录任务、远程窗口及远程服务连接阻止退出。
单独开启远程监听不保活；状态发现轮询不刷新空闲时间。
正常退出后约60至65秒关闭；崩溃客户端需先等待原有租约过期，不承诺立即释放。
