# 0.3.0 第四阶段：共享 Python SDK 与调试 CLI

日期：2026-10-03。分支：`codex/v0.3.0-shared-runtime`，接续第三阶段 `e30aea6`。
继续主机端迁移，未修改下载器固件、WinUSB 或正式安装版。

## 改造结果

- 新增公开 `SharedDevice` / `connect_shared`。通过现有后台访问内存、寄存器、
  调试控制、通用能力和任务；不实例化 Device/串口，不自动回退或重试。支持上下文
  管理，退出只结束 SDK 会话；SDK 退出后仍可查询已提交任务。
- 会话新增 sdk 类型，管理页显示并沿用已有会话续期、结束会话与采集订阅规则。
  共享 SDK 默认写后校验，拒绝短读/损坏响应；清理异常不掩盖原操作异常。
- `halt`、`resume`、`step`、`read-flash` 改为共享 CLI，支持稳定 ID/别名选择，
  删除对应旧直连函数。共享 CLI 总数为 15，MCP 可通过 `gui_call` 调用新增调试能力。
- 暂停、恢复和新增单步 REST 路由使用异步资源租约及工作线程。等待 CDC 时后台
  仍可响应状态查询，仍受采集/独占任务/其他硬件请求的互斥控制。
- `read-flash` 读取内存映射 Flash，单次 1..4096 字节，输出 JSON；不加载 FLM，
  不再支持 `--save` 写下载器文件。需专用算法的非映射存储器不在此入口范围。
- 后台协议升为 5。独立 Site Agent 包继续排除共享后台及 SDK 模块；未修改安装器。

新增第二只下载器只做连接、状态及磁盘身份查询，未操作其目标 Flash、RAM 或
执行控制。本轮测试后台及采集已停止；截图、日志和设备标识保存在忽略目录。
这证明重新插入新设备后的发现和共存，不代表操作中拔插、休眠或长时间运行验收。

会话；原失败调用不会自动重放。定向测试最初缺少身份解析夹具，补齐后通过。
