# STM32F103RET6 四档与配套固件验证

2026-09-14，开发分支记录；最终性能矩阵和 GUI 校准仍在进行。

主机已统一 ARM SWD / HPM JTAG 的 4/10/20/30 MHz 档位，默认 10 MHz。20/30 MHz 必须获得对应接口的精确固件回执；旧固件失败回退 1 MHz，不冒充高速。

配套 pipe-r20 UF2 SHA256：`85b51a4fb19eef7a0414bf9d09f8f5d70c0a6eded9b69ed88667f15319a2ec00`。STM32F103RET6、72 MHz、RT-Thread 5.1.0；探针 HPM5301、360 MHz。

已完成同版验证：USB 接收暂停及四档启停 20 项、真实 CDC 参数变化 12 项、四档 RTT 回显与 8 次 SystemView、CLI 四档和真实 MCP 四档 4B/4096B。RTT/SystemView 启动并发修复通过 16 轮切换、32 次启动的回执及描述符检查。Keil 1/2/5/10 MHz 编程校验和逻辑分析仪测量通过，数据阶段读写频率误差小于 2%。

主机软件相关检查分别为 108 项和 32 项，存在覆盖重叠，不相加为独立测试总数。旧固件回执拒绝和保守回退仍保留。

本版 HPM 批组帧和精确时间戳换算已实现并通过实际 C 代码测试；当前连接 ARM 板，本版 HPM5301/HPM6E80 真机回归尚未完成。历史 HPM 数据不能改标为新固件收益。未发布安装器、标签或正式固件通道。
