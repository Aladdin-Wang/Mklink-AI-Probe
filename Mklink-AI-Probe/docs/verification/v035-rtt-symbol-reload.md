# 0.3.5 RTT 通道选择与符号重载

2026-10-15，继续 `codex/0.3.5-fixes` / PR43，修改前为 `0093c392`。

## 行为

- RTT 启动时解析真实控制块，自动采集可用的上行通道；界面显示通道复选框，
  勾选仅控制显示，保留隐藏通道的数据与历史。选择保存在本地，切换仪表盘后仍生效。
  地址、搜索、通道、开始/停止合并为一行，删除逗号通道输入及常驻说明。
- 文件监视先离线比较 RTT 地址及已选 SuperWatch 变量的名字、地址和类型。
  布局不变时更新符号，RTT 会话不重启；不再显示常驻“符号文件变化”提示。
- 地址或已选变量布局变化时保留旧符号及采集，只显示“重新加载”按钮。
  用户烧录板上固件后点击按钮，才应用新地址并恢复之前运行的采集。
  同名变量重新绑定，已消失/改名的旧变量移出采集，新名字出现在目录供选择；
  不猜测不同名字的对应关系。完成通知短暂显示后消失。
- 保留用户明确停止的状态，SuperWatch 暂停状态也保留。旧 SDK 符号会话仍受
  失效保护；其他目标采集或操作占用时延后，不抢占、不自动重放未知操作。
- 用户明确要求由按钮决定切换时序：编译完成不能证明板上已运行新固件。
  因此没有后台自动等待控制块再启动的逻辑。

## 烧录异常与交付边界

在用户使用 Keil 前，本轮源码后台尝试过一次测试 HEX 烧录，进度 2% 失败，
返回 `Failed to write file,addr: 0x2000`，任务记为 unknown。没有自动重试。
用户随后自行通过 Keil 烧录并明确通知完成，才继续符号重载验证。
后续 RTT/SuperWatch 成功不能证明该后台烧录故障已修复，也不改写 unknown 记录。

测试没有修改电压或下载器固件。原工程保留本轮测试变更；临时源码后台和测试
浏览器在完成后正常退出并释放下载器。私有日志、端点、截图在构建根
`artifacts/v035-live-symbols`，不提交硬件路径、标识或令牌。
构建均经 `scripts/build_workspace.ps1`；后台持有主构建锁时，后续回归使用
该 artifacts 下独立构建根。含测试联接的临时 run 按规则保留，没有强删。

当前变更仅源码及生产 Web，未重新制作安装器、覆盖安装或更新全局 Skill。
当前桌面包仍不包含本轮和此前拔插自动连接修复。PR43 保持草稿，未合并、签名或发布。
旧固件 legacy RTT 仍只能同时采集一个通道，多通道能力依赖 mux 固件。
