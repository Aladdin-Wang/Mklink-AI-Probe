# SuperWatch 分组易用性验证

## 修改与原因

实际桌面操作发现迁移的空组挤占波形空间，空名称难以识别，整理按钮拥挤，保存尚未结束时第二次修改被丢弃。

- 仅为含可见信号的组分配波形空间；空组仍可编辑，移入信号即显示，折叠列表不影响波形。
- 保存操作依次提交，使用最新 revision 和配置；连续加粗/采样点操作不会互相覆盖。
- 整理/完成、全选/清空勾选文案明确，移动菜单适应窄侧栏。
- 自动命名新组，空名称回退；中文名称和别名仍可复制与保存。
- 可见波形区调整高度按分组 ID 更新，不误改隐藏空组。

## 证据

- Python 全量：2458 passed、2 skipped。
- GUI 全量：72 files、760 passed；定向用例覆盖排队提交、空组及分隔条定位。
- Vue/TypeScript 生产构建通过。
- 真实 Chrome 加载源码组件、真实工作区 API、合成三信号：新建空组保持两幅图；移动一个信号后变为三幅图；点模式与折叠操作保持波形区数量。截图及原始日志留在忽略的 .build/reports。
- 前一 PR18 安装版 1a44c92 已完成桌面/Web 和 V4/F103 110693 次采集零错误/丢样；详细安装记录在 PR19。本轮新二进制验收在构建覆盖后追加，合成数据不作为硬件证据。
