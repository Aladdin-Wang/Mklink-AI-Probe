# 0.3.2 真机验收收敛表

本表单独追踪仍未闭环的实体边界，不把源码测试、构建成功或旧版本的验收直接移作通过。
用户补充要求：Keil 仿真/下载、其他 IDE 和其他数据流占用不能造成上位机误断连；
SWD 仍可识别芯片时，V4 屏幕也不能显示断开。USB 连接、调试仲裁和目标读取失败需要分别判断。

## 本轮基线

- 主机候选源码 `e1eee01e`，Windows NSIS 提取的冻结后台 0.3.2，非覆盖安装态。
- NSIS SHA256 `022c90d7dcf6e9324f690445083d3a06412ec659e47862a68f797b969abe4c89`。
- 探针 V4.6.4，UF2 SHA256 `2684d90424d984d2a2bf5f816fbc80fc30a2d9df60fa35e131c860872bfcff1e`。
- 目标 STM32F103，AXF 的 Flash 加载段 113304 B 读回一致；已备份完整 512 KiB。
- 私有证据在主工作区 `.build/artifacts/v032-e1eee01e/hil/`。
- 没有改 VCC。烧录仅使用刚备份且已验证的应用区，不覆盖未知目标程序。

健康负载阶段没有自然触发 status 5；随后 Keil 下载/调试阶段记录到 155 次固件读取错误。
主机未停止采集或断连，调试占用期间采样暂停，退出后完整采样数从 667999 持续增长，
错误计数保持 155。采集接收队列、CRC 和解析丢字节均未增加。
这是实际调试干扰恢复证据，不等于拔断 SWD 后持续芯片识别失败的验证。
