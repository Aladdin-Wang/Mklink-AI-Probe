## 未收敛的实际失败

`15-flash-matrix` 的在线任务已经完成 erase/program/verify/reset，RTT8、Watch4
自动恢复检查通过。但随后在采集并行状态下进行完整 Flash 回读，出现
`Serial worker write failed`，矩阵中止，不能将整项标为通过。

失败后 USB 及两路串口仍正常枚举，worker 进程仍在；明确重新连接在 0.52 秒内
恢复，芯片 ID 再次正常。未重插、修改供电、重刷固件或盲目重放烧录。
这些现象尚不足以判断故障来自主机还是固件。固件会话正在只读协查。

上位机检查发现 `SerialException` 继承 `OSError`，导致 worker 返回的具体错误也被
统一包装成写入失败。当前源码保留原异常，普通管道错误保留其原因文本；6 项相关
测试通过。此修改还未进入上述冻结包，不能用旧包通过代替新代码验收。

只读并行回读补测仍在进行。保留首发失败，单次重试通过不自动消除此门槛。
脱机/共享烧录负向恢复、V3 Keil/OpenOCD、最终程序保全及释放仍须完成。
