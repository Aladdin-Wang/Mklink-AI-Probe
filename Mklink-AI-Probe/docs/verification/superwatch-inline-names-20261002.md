# SuperWatch 原位命名

- 分组标题和变量名称支持双击或悬停铅笔编辑，不再另起编辑行。
- Enter 保存、Escape 取消、失焦保存；中文输入法合成阶段不提交，失败保留草稿。
- 清空变量别名恢复原始名称，原始名称悬停可见；空组名保持原名称。
- 排序/删除按钮位于分组标题行；变量移组保留拖拽和批量菜单，删除每行常驻下拉框。
