# 0.2.3 安装版 STM32F103 回归（2026-10-02）

## 环境与范围

用户更换 STM32F103RET6 板后，使用已覆盖安装的 Windows 0.2.3
（界面构建号 `22669a7108d3`）和本地更新的 Skill，连接 V4.5.2 探针。
器件 Flash 容量寄存器读出 512 KiB，SWD DPID 为 `0x1ba01477`。
本轮未修改软件源代码或升级探针固件；目标使用现有 RT-Thread 测试应用。
安装包、HPM 及构建证据见 [集成报告](v0.2.3-integration-20261002.md)。

## 启动时序与验收边界

最初在连接后的异步初始化窗口启动 RTT 得到 HTTP 409，脚本仅等到
`READY` 仍不足以判断芯片初始化结束。确认 DPID 识别完成后启动成功，
后续 RTT/SystemView 正常。初次错误未保存响应体，因此不把其具体服务端
原因描述为已经完整定位；本轮未为这一时序现象修改固件或应用代码。

本轮证明表中流程的 CLI/Web/桌面一致性，不代表所有功能全覆盖。
未重复 UART、RS485/Modbus、实体按键脱机烧录、看门狗、低功耗、WRP、
安全加锁或电源测量精度认证。保留用户已同意的 nRF54L15 在线 GUI
保护操作实机闭环缺失限制。未更新 V2/V3，未签名、打标签或正式发布。

原始脚本、备份、日志和截图留在本机忽略的 `.build/reports/v023-f103`；
不提交硬件路径、设备序列号、固件或截图。安装包与 Skill 无需重建。
