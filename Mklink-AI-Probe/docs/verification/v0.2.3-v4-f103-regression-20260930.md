# V4 / STM32F103RET6 回归验收（2026-09-30）

## 环境和边界

- 用户已安装的 V4 固件报告版本 V4.5.2，SWD pipe-r21；主机使用 codex/0.2.3-dev 源码。
- 目标 STM32F103RET6：DP ID 0x1BA01477，Flash 512 KiB。现有应用 114840 字节，与工程二进制完整一致。
- 应用从 0x08005000 开始；预先备份 20 KiB Bootloader，后续下载仅擦写应用扇区。
- UART 115200 已接；RS485 未接。供电只读，未改变电压设置。原始日志和备份保存在用户工程的 .mklink/v4-full-20260930，不提交硬件标识或二进制。

## 已完成

- UART：30 次 help，1324 字节/次，逐字节一致。
- 电源：固件 raw 10 次、CLI 6 次、MCP 20 次加重连读取；V4 电压/电流/功率均有值，单位和功率公式一致。初次约 3456 mV / 39.879 mA / 137.822 mW。无外部仪表，不能据此认证绝对精度。
- USB：241 次 DP ID 读取、5 次 SET_CONFIGURATION 重配置。长匹配重试中 EP0 控制请求响应，中止约 20.95 ms；随后继续读 ID 成功。100 kHz、1/5/10/20/30 MHz 正常，15 MHz 按既有策略拒绝。
- Memory / SuperWatch：真实 HTTP 后端三场景通过：Memory→SuperWatch→Memory；目标软件复位后 SuperWatch 首读；重连后 SuperWatch 首读。无 CLI 预热。4096 字节数组及 47 字节非对齐读写、全零、恢复一致。
- 流：10/20/30 MHz 的单 word 30 秒、多地址 8 秒、4096 字节分块 10 秒、窄值及非对齐 8 秒，数据/CRC/帧丢失/固件丢样检查通过。单 word 主机实收约 114273 / 165085 / 184584 次/秒，不能等同于多变量采样率。
- 启停：20 次三档切换流启停后命令回读、5 次初始化重连通过。
- 对齐：4/10/20/30 MHz，偏移 0..3、长度 1/2/3/4/5/7/16/31/513 字节，以及目标执行两种 word 值交替、按 byte/halfword 采集通过；RAM 和 CPU 寄存器恢复，tick 继续推进。
- CLI：三档 dump、串口枚举、SystemView 通过。
- 实际 stdio MCP：符号、变量、内存、flush、核心寄存器、halt/step/resume、安全状态只读、三档采样与 RTT、SystemView、UART 通过。
- RTT 回显：4/10/20/30 MHz，各 50 × 256 字节一致。最初 30 MHz 两次逐调用比对误报：后台 rtt_tick 行跨读取边界；原始片段重组后全部一致，未据此修改产品代码。

## 烧录、调试与界面最终结果

- 在线烧录：10/20/30 MHz × under-reset/halt，共 6 轮。每轮擦写选定应用扇区、下载、校验，再用命令通道独立回读 114840 字节；应用一致，20 KiB Bootloader 一致，复位后 tick 推进。
- 探针端脱机算法路径：10/20/30 MHz × 2，共 6 轮；设备端校验成功，并独立完整回读应用与 Bootloader。未执行断开 PC 后物理按键下载。
- RTT 大块上行：三档各 5 次，每次 8191 字节，全部一致。暂停 CPU 后备份/填充/读取/恢复 8192 字节 RTT 缓冲区，随后恢复 CPU。旧脚本的终端提示写着 x10，实际循环和 JSON 记录均为每档 5 次。
- VOFA：16 路连续 float 快速模式 1546 帧；float/int8/uint8/非对齐 int16 四路精确模式 1262 帧，所有值一致。原始起始字节证实 REPL 命令回显及提示符导致启动时一次重同步（42/115 字节）；首个有效帧以后新增解析丢帧为 0。测试 RAM 已恢复。
- HardFault：受控 UDF 触发 CFSR=0x10000、HFSR=0x40000000，定位 mklink_hardfault_demo_entry / main.c:145；复位后清零且 tick 推进。GUI 最终显示“无 HardFault”。
- 硬件断点：命中 rt_tick_increase，核心 PC 与断点地址一致；清除断点、恢复后 tick 推进。
- 真实浏览器：已配置三变量 SuperWatch 曲线和 u8=8/u16=16 可见，累计 686585 次后停止，read_errors/read_drops 均 0；随后 Memory 页面读取测试数组 64 字节正确。GUI u8/u16/i8/i16 写入、回读确认与恢复全部 verified=true。
- UART GUI：115200/8N1，发送 help+CRLF，收到 1324 字节，终端内容正确；关闭端口成功。
- RTT GUI：固定控制块启动，后台 tick 文本和 V4_GUI_RTT_CHECK 回显可见，停止成功。
- RTOS Trace GUI：状态快照 144930 个事件、13 个任务、72 MHz，同步成功，解析丢字节/包及传输丢弃均 0。显示 1 个目标历史 overflow 事件，基线后目标新增丢包为 0；不能表述为目标从未发生 overflow。

## 收尾

最终独立核对应用全量、Bootloader 和 4096 字节测试数组均一致，CPU 运行，无 HardFault、无遗留硬件断点。最终遥测约 3456 mV / 41.519 mA / 143.490 mW。测试后台已关闭，命令口/UART 已释放。

本轮未发现需要修复的探针固件缺陷，未修改或重刷 MicroLink.uf2，未改目标应用源码。最初 COM 打开被拒绝由用户关闭占用程序后恢复；本轮没有卸载驱动或修改注册表。RTT 两个比较误报通过跨读取边界重组原始证据排除。

## 不包含

RS485/Modbus 实物链路、JTAG、外部仪表标定、实际拔线压力、断开 PC 后物理按键脱机下载、加锁/解锁/OTP、其他芯片、安装包升级/发布。本报告是本机固件功能回归，不替代全产品或所有芯片认证。
