# 0.3.5 串口文本分行修正

f517088c 将每个接收批次立即新增为一行，解决了无换行尾段不显示的问题，
但错误地把传输批次当作文本行。串口文本任意分批时，`seq`、`tick` 等字段
会跨两条日志记录；原始字节完整并不能证明文本排版正确。

修正保留即时发布，增加行片段的续接标记。未换行的片段立即可见，后续片段
续接上一条记录；CR、LF 产生逻辑行，跨批次 CRLF 只换一行。方向变化与
端口/会话重置隔离续接，发送操作分别展示。无换行长流每 4096 字节分段，
避免无限增长；5000 条记录上限与虚拟滚动保持。

显示层保留首片段的时间与编号，续接时合并原始字节。字符串不再展示转义的
CR/LF；HEX 与原始导出仍包含全部字节。此处逻辑行仅用于显示，不认定协议帧。
