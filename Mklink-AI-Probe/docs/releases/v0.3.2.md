# MKLink AI Probe v0.3.2

本次更新完善跨平台 USB 识别、共享连接与采集体验，并新增 macOS、Linux 桌面安装包。

- 修复 macOS USB 接口号识别，完善 Linux 串口发现；按设备身份识别脱机烧录盘，兼容 macOS、Linux 和 Windows。
- 改善 GUI、AI 与 IDE 共用探针时的连接状态、重连及退出释放；修复临时心跳失败后会话停止续租的问题。
- 修复 RTT/SuperWatch 运行时在线烧录文件检查冲突，完善烧录前自动暂停、结束后恢复采集；改善偶发目标读错的处理。
- 固件升级支持 CHERRYUF2 自动识别；旧设备不能自动进入升级模式时，提供固件下载和手动升级说明。
- SWD 时钟使用 MHz 输入；RTT 与串口“收发”视图显示方向及毫秒时间，多 RTT 面板可分别调整大小，串口扩展功能默认收起。
- 新增 macOS Apple Silicon、macOS Intel 和 Linux x64 桌面包，提供各安装格式对应的自动更新载荷。

Windows 使用 NSIS 安装包；Mac 按处理器选择 DMG；Linux x64 可选 DEB 或 AppImage。Mac 包尚未经过 Apple Developer ID 公证。Linux USB/串口权限配置见随包说明。Mac/Linux 的真实设备与原地升级验证由用户后续反馈，不等同于本次云端包检查已覆盖这些场景。
