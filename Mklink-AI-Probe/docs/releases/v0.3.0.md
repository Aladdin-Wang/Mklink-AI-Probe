# MKLink AI Probe 0.3.0

- GUI、AI、CLI、MCP 共用下载器连接，支持多设备独立运行和远程仪表盘。
- 配套 V3/V4 新固件支持八通道 RTT，与 SuperWatch 并行采集。
- 优化高速采样、波形缩放与调试共存，AI 可按需切换 GUI 展示调试结果。
- 修复 Web AXF 加载、多窗口启停，完善 HPM BIN/HEX 烧录。

本次同时提供上位机、Skill、MicroLink V3.6.0 / V4.6.0 与 HPMLink V4.6.0 固件。请配套更新；仅升级上位机不会为旧固件增加多通道 RTT、调试共存等新固件能力。V3 不支持 HPM。继续使用 CDC，无需新增 WinUSB。

已知限制：HPM/SES 部分退出方式会遗留调试占用，后续连接可能需要断开调试器并重插下载器；该场景尚未完全修复。调试器优先，下载期间采集会间断；采样率取决于目标和调试负载。长期、跨物理主机及所有芯片组合未完整认证。Windows 安装包尚无 Authenticode 签名，自动更新包使用独立的更新签名校验。
